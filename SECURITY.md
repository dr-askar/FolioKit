# Security

Do not post private documents, signing keys, tokens or exploitable vulnerability details in public issues.

If GitHub offers **Security → Report a vulnerability** for this repository, use that private channel. Otherwise open a minimal issue requesting a private contact method without including exploit details or sensitive files. There is no guaranteed response time or supported-version policy yet; Android releases are previews.

Download APKs from this repository's Releases page and compare their SHA-256 checksums with the attached SHA256SUMS.txt. Keep your operating system and Android System WebView updated.
